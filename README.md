# 🎞️ Clip Editor

A Python microservice that performs automated video editing on downloaded clips for short-form platforms like YouTube Shorts, TikTok, and Instagram Reels.

## Features (Planned)

- Trim/split
- Resize/reformat (9:16)
- Add subtitles (burned-in)
- Overlay watermark
- Add intro/outro music
